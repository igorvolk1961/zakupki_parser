# Компетенции поставщика (пример для тестовой выборки)

Поставщик — ИТ-компания, специализирующаяся на услугах в области информационных
технологий и разработке программного обеспечения (ОКПД2: разделы 62 и 63).

## Основные компетенции

1. **Разработка программного обеспечения.** Проектирование, разработка, доработка
   и сопровождение заказного ПО, веб-приложений и корпоративных информационных
   систем. Разработка API и интеграционных модулей.

2. **Автоматизация бизнес-процессов.** Внедрение систем автоматизации документооборота
   и управления предприятием, интеграция с существующими системами заказчика,
   миграция данных из устаревших систем.

3. **ИТ-инфраструктура и сопровождение.** Обслуживание серверов и сетевого
   оборудования, администрирование операционных систем и баз данных, обеспечение
   информационной безопасности, техническая поддержка пользователей.

4. **Консультационные услуги в области ИТ.** Аудит ИТ-инфраструктуры и программного
   обеспечения, консультации по выбору программных решений, сопровождение проектов
   внедрения, обучение сотрудников заказчика работе с ПО.

## Отличие от близких, но не релевантных тем

Компетенции касаются **программных** и **информационных** решений. Закупки по
поставке «железа» без ПО, бытовой техники, аудио/видеоаппаратуры, консультации по
оборудованию, не связанному с информационными технологиями, НЕ входят в компетенции,
даже если используют схожие слова («системы», «консультации», «автоматизация»).
