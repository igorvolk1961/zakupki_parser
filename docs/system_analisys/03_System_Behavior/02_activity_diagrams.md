## Обоснование избыточности

**Статус**: Документ содержит обоснование отсутствия детальных диаграмм активностей (Activity Diagrams / BPMN) на текущем этапе проектирования.
**Причина избыточности**:
    **Дублирование бизнес-логики**: Вся сложная условная логика системы (например, алгоритм проверки требования опыта по ПП РФ № 2571 или контекстный анализ реестра Минпромторга) уже полностью и однозначно зафиксирована в артефакте «Каталог бизнес-правил (Business Rules Catalog)» (BR-03, BR-04) в формате четких условий «ЕСЛИ → ТО».
    **Достаточность диаграмм последовательности**: Взаимодействие компонентов системы при выполнении этих правил уже детально описано в Диаграммах последовательности (Sequence Diagrams) Уровня 3. Разработчику понятно, кто, когда и какие данные передает.
    **Принцип DRY (Don't Repeat Yourself)**: Создание BPMN-диаграмм для процессов, которые уже описаны текстовыми бизнес-правилами и диаграммами последовательности, приведет к дублированию информации. При любом изменении логики придется синхронизировать три артефакта вместо одного, что повышает риск рассинхронизации документации и кода.
