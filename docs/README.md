# Документация проекта

## Метрика «Стоимость обработки закупки»

Полная стоимость обработки закупки (скоринг + анализ) хранится в
`procurement_evaluations.costs` (JSONB) и отображается в карточке/модалке UI для
роли `analyst` без нажатия «Трейс».

Структура поля:

```jsonc
{
  "scoring": { "usd": 0.0012 },          // скоринг (fit/judge/refine)
  "analysis": { "usd": 0.0008 }          // анализ ТЗ
}
```

Поле `costs` отдаётся в API только для роли `analyst` (сервер не отдаёт
стоимость обычным пользователям).

### Миграция существующей БД

Колонка добавляется через Liquibase-changeset `db.changelog-1.48.yaml`
(`ALTER TABLE procurement_evaluations ADD COLUMN IF NOT EXISTS costs JSONB;`, что
подключается `run_migrations` при старте сервиса). На свежей БД колонка также
создаётся автоматически (`create_all`).

Колонка nullable — обратная совместимость сохраняется (для старых записей
`costs = NULL`, строка стоимости в UI не отображается).
