## Услуги

1. **Аудит и проектирование бизнес-процессов** — изучение процессов, поиск узких мест,
   проектирование целевой архитектуры, расчёт эффекта автоматизации (2–3 дня).
2. **ИИ-юристы** — анализ договоров (риски, условия, сверка с шаблонами), скорость ×20.
3. **ИИ-ассистенты** — объединение данных из CRM/ERP/Excel, дашборды в реальном времени,
   прогнозы и рекомендации (RAG).
4. **ИИ-менеджеры** — автоматическое ведение сделок в CRM, напоминания, коммерческие
   предложения, контроль дедлайнов.
5. **ИИ-аналитика** — глубокий анализ корпоративных данных: тренды, прогнозирование спроса,
   выявление аномалий, рекомендации.
6. **ИИ-колл-центр** — анализ звонков: распознавание речи, тональность, контроль скриптов,
   оценка по критериям через LLM.
7. **Автоматизация бизнес-процессов** — интеграция CRM/ERP/бухгалтерии/склада в единый поток,
   триггеры, уведомления, отчёты (ручные операции −80%).
8. **Разработка платформ и сервисов** — веб-платформы, мобильные приложения, внутренние
   сервисы; от MVP до масштабирования.
9. **Создание AI-контента** — видео и изображения с помощью ИИ (реклама, визуалы, соцсети).

## Этапы работы

Аудит и анализ процессов (2–3 дня) → проектирование решения (3–5 дней) → пилотный проект
MVP (1–2 недели) → обучение на ваших данных → внедрение и интеграция (CRM/ERP и др.) →
сопровождение и развитие (постоянно: техподдержка, мониторинг качества, обновление моделей,
масштабирование).

## Кейсы / отрасли

- **Юридические услуги** — мультиагентный ИИ-ассистент юриста: тема обращения, ответ по базе
  законов (RAG), проверка статуса в Битрикс24, время ответа ~15 сек.
- **Продажи / B2B** — ИИ-анализ звонков и оценка менеджеров по 6 критериям через LLM,
  автоквалификация лидов, запись в Битрикс24, дашборд ОКК.
- **Финансы / кредитование** — голосовой AI-агент на входящей линии, сбор данных клиента,
  квалификация, отправка заявки в CRM/Telegram/Битрикс24.
- **HR** — Chrome-расширение РКЛ: массовая проверка сотрудников по реестру контролируемых лиц МВД.
