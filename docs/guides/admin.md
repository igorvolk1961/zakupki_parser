# Руководство администратора

Роль **Администратор** предназначена для управления пользователями системы:
создание учётных записей, назначение ролей и управление статусами.

Рабочее пространство администратора состоит из вкладки **Пользователи**.
Если у пользователя несколько ролей, вкладки всех его ролей объединяются
в один интерфейс, а в меню «Документация» появляется отдельный пункт на каждую
роль.

## 1. Вход

Вход выполняется по логину и паролю (Bearer-токен создаётся на сервере).
Заблокированная учётная запись (`blocked`) войти не может.

## 2. Пользователи

Вкладка показывает список пользователей: ID, логин, email, роли, статус
(«активен» / «заблокирован»), дату создания и доступные действия.

### 2.1. Создание пользователя

Кнопка **«Создать пользователя»** открывает форму: логин, email (необязательно),
пароль (не менее 8 символов) и роли. Назначать можно роли `admin`, `analyst`,
`devops`; роль **простого пользователя** (`user`) выдаётся только при
саморегистрации и администратором не назначается.

### 2.2. Роли

Кнопка **«Роли»** у пользователя открывает окно смены набора ролей
(`admin`/`analyst`/`devops`). Нельзя менять роли простых пользователей
(единственная роль `user` — неприкосновенна) и роли собственного аккаунта.

### 2.3. Статус

**«Заблокировать»** / **«Разблокировать»** переводит учётную запись в статус
`blocked`/`active`. Заблокированный пользователь не может войти в систему.

### 2.4. Удаление

**«Удалить»** безвозвратно удаляет пользователя вместе с его профилями
и оценками. Нельзя удалить собственный аккаунт и последнего администратора.
