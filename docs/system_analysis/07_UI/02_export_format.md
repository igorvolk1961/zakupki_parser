# Спецификация экспортов

> Формат выгрузок. CSV — текущее состояние (`POST /api/procurements/export`,
> `src/zakupki_parser/api/app.py` → `CSV_COLUMNS`); XLSX — целевое (US-3.3, US-6.1/6.2,
> этап 8, пост-MVP).

## 1. CSV (реализовано, MVP)

- **Эндпоинт**: `POST /api/procurements/export` (тело: `{min_fit_score?}`, порог по умолчанию 0.4).
- **Фильтр**: только активные (`is_active` и срок актуальности) и релевантные
  (`fit_score ≥ min_fit_score`) закупки — как переключатель «Только релевантные».
- **Файл**: `config_service.yaml -> export_dir/procurements.csv`, кодировка UTF-8 с BOM
  (открывается в Excel).
- **Колонки** (плоские, без detail_json/files_json):

| Колонка | Тип | Примечание |
| :------ | :-- | :--------- |
| id | int | идентификатор закупки |
| number | string | реестровый номер |
| platform_id | string | ключ площадки |
| url | string | ссылка на ЭТП |
| customer | string | наименование заказчика |
| procedure_type | string | тип процедуры |
| law | string | 44-ФЗ / 223-ФЗ |
| subject | string | предмет закупки |
| nmck | float | НМЦК |
| publication_date | datetime | ISO |
| update_date | datetime | ISO |
| deadline | datetime | дедлайн подачи |
| execution_term | string | срок исполнения |
| okpd2_codes | string | коды ОКПД2 |
| kpgz_codes | string | коды КПГЗ |
| security_amount | float | обеспечение |
| security_amount_unit | string | единица обеспечения |
| advance | float | аванс |
| score | float | дефолтный скор |
| fit_score | float | Fit |
| p_win | float | вероятность победы (если считалась) |
| margin | float | маржа (если считалась) |
| score_method | string | метод скоринга |
| is_active | bool | активность |

## 2. XLSX (целевое, этап 8 — пост-MVP)

### 2.1 Экспорт предварительного списка (US-3.3)
- Колонки: реестровый номер, заказчик, закон, НМЦК, дедлайн подачи, предмет закупки,
  Fit, ссылка на ЭТП.
- Форматирование: числа, даты, гиперссылки.

### 2.2 Сводка «В работу» (US-6.1/6.2)
- Только закупки со статусом «В работу» (этап 7, `procurement_evaluations.status`).
- Колонки: реестровый номер, заказчик, закон, НМЦК, дедлайн подачи, предмет закупки,
  Fit, **маркеры проверок** (опыт / реестр Минпромторга / лицензии, 🔴/🟡/🟢 +
  краткое описание), ссылка на ЭТП.
- **Дисклеймер** в подвале файла (NFR-SEC-4): «Результаты автоматизированного
  скоринга носят исключительно информационный характер и не являются юридической
  консультацией. Окончательное решение о соответствии требованиям закупки и подаче
  заявки принимает пользователь».

## 3. Общие требования

| # | Требование | Связано с |
| :-: | :--------- | :-------- |
| E-1 | Все экспорты — через эндпоинт за авторизацией (`require_user`) | US-3.3 |
| E-2 | Даты в ISO-формате, числа — с исходной точностью | — |
| E-3 | Дисклеймер обязателен в любом экспортируемом отчёте (NFR-SEC-4) | US-9.1 |
| E-4 | ПДн физлиц в экспортах отсутствуют (маскируются/не сохраняются) | US-9.3 |
| E-5 | Экспорт безопасен при работающем парсере (read-only) | — |
