# Шаблон карточки тендера (требование к UI/данным)

> Требование к представлению карточки закупки (SA-4.3): поля, маркеры, дисклеймер.
> Покрывает US-3.2, US-4.5, US-6.2 и NFR-SEC-4. Связано с `07_UI/01_ui_requirements.md`.

| Поле | Источник в API | Обязательность |
| :--- | :------------- | :------------- |
| Реестровый номер | `number` | ✅ |
| Площадка | `platform_id` | ✅ |
| Заказчик | `customer` | ✅ |
| Закон | `law` (44-ФЗ / 223-ФЗ) | ✅ |
| НМЦК | `nmck` | ✅ |
| Дедлайн подачи | `deadline` | ✅ |
| Срок исполнения | `execution_term` | ⬜ |
| Обеспечение/аванс | `security_amount`, `advance` | ⬜ |
| Коды ОКПД2/КПГЗ | `okpd2_codes`, `kpgz_codes` | ✅ |

## 2. Специфические проверки (US-4.5; реализовано)

Раздел «Анализ ТЗ (стоп-условия)» с маркерами по каждой проверке. Системные проверки
(`source=system`) обязательны для каждой закупки, не зависят от профиля и не
редактируются; вердикты вычисляются правилами `matcher.py` (Stage B) по фактам ТЗ и
фактам профиля.

| Проверка | Источник | Маркер | Описание |
| :------- | :------- | :----- | :------- |
| Опыт (ПП РФ 2571) | системная (`sys:exp_2571`) | 🔴 / 🟡 / 🟢 | 🔴 — подтверждение через площадку, в профиле нет; 🟡 — допускаются сканы актов/выписка из реестра; 🟢 — не барьер / опыт в профиле есть |
| Реестр Минпромторга | системная (`sys:minprom_registry`) | 🔴 / 🟢 | 🔴 — требуется выписка; 🟢 — «не установлено» (BR-04) |
| Лицензии/СРО/допуски | системная (`sys:license_sro`) | 🔴 / 🟡 / 🟢 | 🔴 — требуется вид, которого нет в профиле; 🟡 — вид не распознан, требует проверки; 🟢 — не требуется / лицензия есть |
| Вопросы клиента | профиль (`source=profile`) | 🔴 / 🟡 / 🟢 | вердикты LLM по пользовательским вопросам профиля (absolute/soft/no_stop_condition) |

Цветовая кодировка: 🔴 — жёсткий барьер, 🟡 — мягкое требование / уточнение,
🟢 — требование не установлено / не требуется. Спорные случаи маркируются 🟡,
а не удаляются (recall-over-precision).

## 3. Дисклеймер (NFR-SEC-4, US-9.1)

Внизу карточки (и в подвале экспортов) обязателен текст:

> «Результаты автоматизированного скоринга носят исключительно информационный
> характер и не являются юридической консультацией. Окончательное решение о
> соответствии требованиям закупки и подаче заявки принимает пользователь».
