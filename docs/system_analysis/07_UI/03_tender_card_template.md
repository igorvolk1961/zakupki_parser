# Шаблон карточки тендера (требование к UI/данным)

> Требование к представлению карточки закупки (SA-4.3): поля, маркеры, дисклеймер.
> Покрывает US-3.2, US-4.5, US-6.2 и NFR-SEC-4. Связано с `07_UI/01_ui_requirements.md`.

## 1. Базовые поля карточки (US-3.2)

| Поле | Источник в API | Обязательность |
| :--- | :------------- | :------------- |
| Реестровый номер | `number` | ✅ |
| Площадка | `platform_id` | ✅ |
| Заказчик | `customer` | ✅ |
| Закон | `law` (44-ФЗ / 223-ФЗ) | ✅ |
| НМЦК | `nmck` | ✅ |
| Дедлайн подачи | `deadline` | ✅ |
| Срок исполнения | `execution_term` | ⬜ |
| Обеспечение/аванс | `security_amount`, `advance` | ⬜ |
| Коды ОКПД2/КПГЗ | `okpd2_codes`, `kpgz_codes` | ✅ |
| Предмет закупки | `subject` | ✅ |
| Тип процедуры | `procedure_type` | ✅ |
| Fit | `fit_score` | ✅ |
| P(win) / Margin | `p_win`, `margin` | ⬜ (если считались) |
| Ссылка на ЭТП | `url` | ✅ |
| Статус | `status` (этап 7) | ⬜ |

## 2. Специфические проверки (US-4.5, этап 5)

Раздел «Специфические проверки» с маркерами по каждой формальной проверке:

| Проверка | Маркер | Описание |
| :------- | :----- | :------- |
| Опыт (ПП РФ 2571) | 🔴 / 🟡 / 🟢 | 🔴 — подтверждение через площадку; 🟡 — допускаются сканы актов; 🟢 — не барьер |
| Реестр Минпромторга | 🔴 / 🟡 / 🟢 | 🔴 — требуется выписка; 🟡 — уточнение; 🟢 — «не установлено» (BR-04) |
| Лицензии | 🔴 / 🟢 | 🔴 — требуется лицензия (указать какая); 🟢 — не требуется |
| Другие вопросы профиля | 🔴 / 🟡 / 🟢 | вердикты RAG по вопросам профиля (absolute/soft/no_stop_condition) |

Цветовая кодировка: 🔴 — жёсткий барьер, 🟡 — мягкое требование / уточнение,
🟢 — требование не установлено / не требуется. Спорные случаи маркируются 🟡,
а не удаляются.

## 3. Дисклеймер (NFR-SEC-4, US-9.1)

Внизу карточки (и в подвале экспортов) обязателен текст:

> «Результаты автоматизированного скоринга носят исключительно информационный
> характер и не являются юридической консультацией. Окончательное решение о
> соответствии требованиям закупки и подаче заявки принимает пользователь».
