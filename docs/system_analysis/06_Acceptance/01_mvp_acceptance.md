# DoD и критерии приёмки MVP

> Скоуп MVP: **этапы 0–5 (4A+4B)** (парсинг, профили, скоринг Fit, RAG-анализ ТЗ).
> пост-MVP (этапы 6, 4C, 7, 8, 9, 10) — вне приёмки MVP.
> Источники: Vision & Scope (критерии успеха), AC user stories, NFR
> (`04_Data_and_NFR/02_non_functional_requirements.md`), матрица трассируемости.
> Актуализировано 2026-08-24.

## 1. Критерии успеха MVP (Vision & Scope)

| # | Критерий | Метрика | Статус |
| :-: | :------- | :------ | :----- |
| K-1 | Сокращение времени ручной проверки тендерологом | с 1–1,5 часа до 10–15 минут в день | 🟡 ожидает эксплуатации |
| K-2 | Выявление и маркировка специфических ограничений (опыт, реестр, лицензии) в тестовой выборке | точность/полнота на тестовой выборке ≥ согласованных порогов (методика — SA-4.1) | 🟡 RAG-вердикты есть; формальные маркеры — этап 5 |
| K-3 | Стоимость обработки одного тендера в заданном экономическом коридоре | ≤ $0.05 на глубокий анализ (NFR-COST-1) | 🟡 подсчёт стоимости — этап 5/10 |

## 2. Definition of Done (DoD) для задачи/этапа MVP

- Реализация покрыта unit-тестами; интеграционные тесты — при доступном DSN.
- `ruff check`, `ruff format --check`, `mypy`, `zp check-config` — без ошибок.
- Устаревшие тесты заменены/удалены (принцип трекера `plans/plan.md`).
- Приложение сохраняет работоспособность (заглушки вместо отсутствующего функционала).
- Обновлены соответствующие артефакты `docs/system_analysis/` (статусы, расхождения) —
  регламент SA-5.1.

## 4. Измеримые NFR для приёмки MVP

| NFR | Требование | Способ проверки |
| :-- | :--------- | :-------------- |
| NFR-PERF-1 | API ≤ 200 мс (p95) на список/карточку | Нагрузочный прогон `/api/procurements` |
| NFR-PERF-2 | Тяжёлые задачи асинхронны, UI не блокируется | `POST /api/procurements/analyze` возвращает «queued» немедленно |
| NFR-COST-2 | Повторная обработка неизменённого = $0 | Проверка дедупа/пропуска прохода |
| NFR-SEC-1 | Изоляция BR-07 | Тесты: запрос чужого тенанта → 403 |
| NFR-SEC-2 | Секреты в env | Код/репозиторий не содержит ключей |
| NFR-OBS-1 | 100% LLM-запросов в LangFuse | Трейсы с input/output tokens, latency, cost |
| NFR-FT-1/5 | Сохранность задач, идемпотентность | Тесты recovery/повторной доставки |
| NFR-FT-2 | Сбой LLM не роняет парсинг | Имитация недоступности LLM |
| NFR-FT-3 | Circuit breaker | Имитация N ошибок узла |
