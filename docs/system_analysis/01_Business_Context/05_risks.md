# Реестр рисков

> Риски проекта TenderSearch. Вероятность и влияние: Высокая / Средняя / Низкая.
> Оценка риска = Вероятность × Влияние (В=3, С=2, Н=1). Приоритет: Красный (≥6),
> Жёлтый (3–4), Зелёный (≤2). Митигации синхронизированы с BR/NFR и `TODO.md`
> (актуализировано 2026-08-24).
